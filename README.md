# PVC_lab4
4 Лабораторная работа студенток Мельниковой, Горбушиной, Швецовой ИТ-3,4 по ПВС
## Инструкция
1. Скомпилировать программу - *make serial* или *make parallel*. При перекомпиляции из serial в parallel и обратно используйте *make clean*.

2. Сгенерировать lsf скрипт - *make lsf KBLOCKS=n KTHREADS=m EXEC=parallel/serial ARRAY_SIZE=k CYCLES=p*.
**KBLOCKS=n** - программа будет использовать *n Kernel* блоков.
**KTHREADS=m** - программу будет использовать *m Kernel* потоков.
**EXEC=parallel/serial** - выбирайте в зависимости от того, какую программу использовать.
**ARRAY_SIZE=k** - будет использоваться массив на *k элементов*. Каждый элемент весит один байт.
**CYCLES=p** - количество повторений программы.

3. Запустить скрипт из корневой папки проекта - __./lsf/pr*_*.lsf__

Существует скрипт загрузки *bsub* существующими lsf скриптами в папке lsf.

Альтернативно существует вариант запуска автотестов при помощи *make auto*.
